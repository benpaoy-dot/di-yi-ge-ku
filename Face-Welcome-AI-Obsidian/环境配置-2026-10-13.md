## 环境与配置决策

- 系统默认 `python` 是 3.8，另有 Python 3.10 和 Anaconda Python 3.12。
- 使用已安装的 Windows x64 Python 3.10.11 创建项目内 `.venv`，避免混用全局和 Anaconda 依赖。
- 直接依赖固定为 InsightFace 2.1、ONNX Runtime 1.23.2、OpenCV 4.12.0.88、NumPy 2.2.6；使用 CPU 推理。
- InsightFace 库版本采用可直接安装的官方 wheel，项目自带 buffalo_sc 模型及原有识别逻辑保持不变。
- 新增 `requirements.txt` 和全部依赖锁定清单 `requirements-lock.txt`。
- 新增 `配置项目环境.ps1`，将原启动脚本改为明确使用项目 `.venv`。
- `.venv/` 已加入 `.gitignore`；人员数据库仍保持忽略，不上传任何人员资料。
